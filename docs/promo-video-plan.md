| 항목 | 내용 |

## 2. 데모 자산 (녹화용 실제 화면)

녹화에 사용할 커스텀 UI는 이미 구현되어 있음 (`custom-ui-templates` 레포).

| 파일 | 역할 |
|---|---|
| `frontend/src/views/templates/chart/ProductionByProcess.vue` | 공정별 생산량 막대 차트 뷰 (계획수량 vs 실적수량) |
| `frontend/src/views/templates/chart/productionByProcess.ts` | 샘플 데이터 composable (절삭·용접·조립·도장·검사·포장 6공정) |
| `frontend/src/expose.ts` | Module Federation 등록 — `viewRegistry` + `viewMeta` (`ProductionByProcess`, `usePlanCycle: true`) |
| `frontend/src/router/index.ts` | 개발 라우트 `/production-by-process` |

**특징**
- 샘플 데이터 기반 → DB/백엔드 없이 `make dev-frontend`만으로 즉시 렌더 (녹화 중 외부 의존성 실패 위험 0).
- 헤더에 **`계획 버전 · {planVer}` 배지** — 호스트가 주입한 현재 계획 버전을 표시(요청 문장의 "계획 버전 기준"과 시각적으로 일치).
- 플랜 버전 변경 시 차트 자동 갱신(`watch(planVer)`) → 호스트 데이터 실시간 연동 증거.

### 녹화 환경 기동 (인증된 터미널)
```powershell
make install            # @vmscloud 사설 레지스트리 토큰이 있는 ~/.npmrc 필요
make dev-frontend       # vite :5300
# 브라우저: http://localhost:5300/production-by-process
# 상단 플랜 버전 선택기로 버전을 고르면 배지/차트에 반영
```
Host(mozart-cloud)에 붙여 녹화 시 `viewRegistry`의 **`ProductionByProcess`** 키로 로드, 메뉴 기본명 "공정별 생산량".

## 3. 스토리보드 (컷리스트)

좌측 **Claude CLI 터미널** / 우측 **mozart-cloud APS 화면** 분할.

| 컷 | 시간 | 화면 | 자막 | 사운드 |
|---|---|---|---|---|
| **1. 후크** | 0–2s | (우) mozart-cloud 메뉴에 '공정별 생산량' 자리가 비어있음. (좌) 터미널 커서 깜빡 | **새 화면이 필요할 때** | 잔잔한 인트로 |
| **2. 요청** | 2–6s | (좌) 터미널에 B 문장 타이핑 → Enter. 핵심 명사 줌인 | **원하는 화면을, 말로 요청하세요** | 키스트로크음, Enter 직전 0.3초 정지 |
| **3. 매직 점프** | 6–7s | 화이트 플래시/와이프 0.5s — 생성 과정 생략 | (없음) | "휙" 전환음 |
| **4. 결과** | 7–11s | (우) 메뉴에 '공정별 생산량' *팝* 등장 → 클릭 → 막대 차트 렌더. 헤더 `계획 버전` 배지 줌 | **mozart-cloud 안에, 실데이터로 즉시** | 등장 임팩트음 |
| **5. 연동** | 11–13s | 플랜 버전 변경 → 차트 갱신 / 막대 클릭 → 툴팁 반응 | **현재 계획 버전 데이터와 완전 연동** | — |
| **엔드 카드** | 13–15s | 차트가 블러+축소되며 배경 → 슬로건 페이드인 | (엔드 슬로건, 아래 5장) | 짧은 각인음 1회 |

## 4. 컷 2 요청 문장 (확정)

터미널에 실제로 타이핑되는 문장:

> **"이번 계획 버전 기준으로 공정별 계획 대비 실적 생산량 비교 화면이 필요해"**

**선정 이유**
- 개발 용어 0, 업무 언어 100 → "현업 담당자가 말로 요청"하는 진정성.
- "계획 버전 / 계획 대비 실적"이 mozart-cloud(APS) 도메인 신뢰도를 부여.
- 결과 화면(계획 버전 배지 + 계획·실적 막대)과 단어가 1:1 일치 → "말한 그대로 나왔다"는 인과를 시각적으로 증명.

**연출**
- 전체를 치지 말고 핵심 명사("공정별 생산량", "계획 대비 실적")가 입력되는 순간 살짝 줌인 + 굵게. 조사·어미는 빠르게.
- 타이핑 2~3배속 + 키스트로크음. Enter 직전 0.3초 정지로 긴장 → 매직 점프.
- 결과 차트의 축 라벨(공정 / 계획수량 / 실적수량)이 요청 문장 단어와 똑같이 보이게.
